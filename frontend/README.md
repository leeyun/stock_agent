# Trender Web

Trender의 Flutter Web 프론트엔드입니다.

```bat
fvm flutter pub get
fvm flutter run -d chrome --web-port 3000
```

API 기본 주소는 `http://localhost:8000`입니다. 저장소 루트에서 `scripts\web.bat`으로도 실행할 수 있습니다.
